Gmail Cleaner

Move all mail from senders you choose to Trash. Everything runs on this computer.

1Add your Google app file

Choose the credentials.json you downloaded from Google Cloud Console.

How do I get this file?
  1. Open Google Cloud Console and create a project.
  2. Enable the Gmail API, then set up the OAuth consent screen (External; add your own address as a test user).
  3. Credentials → Create credentials → OAuth client ID → Desktop app, then download the JSON.

2Sign in with Google

A Google window will ask you to allow access to your mailbox.

3Choose senders

One per line. Use an address (news@shop.com) or a whole domain (@shop.com). Starred mail is never touched.
